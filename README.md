# Simple_micro-bit_Calculator
## Description
### Materials
You need...
+ a micro:bit with battery pack 🖥️ 🔋
+ the [hex file for the micro:bit](https://downloads.scratch.mit.edu/microbit/scratch-microbit.hex.zip) 📁
+ a little bit of aluminum foil or your hands 🙌
+ [ScratchLink](https://scratch.mit.edu/download/scratch-link) and [Scratch](https://scratch.mit.edu/projects/1388747806/) or [Xcratch](https://xcratch.github.io/editor/#1792240321911) 🌐
### Instructions
1. Put the file for Scratch on the micro:bit
2. Open [the project](https://scratch.mit.edu/projects/1388747806/)#
3. Connect the micro:bit to Scratch
+ Open the Editor
+ Go to the micro:bit extension
+ Tap on the **!** and choose your micro:bit.
4. Then connect one end of the aluminum foil to the GND pin or touch it with one finger
5. With the other side of your aluminum foil (or your finger), touch the 0, 1 or 2 pin to choose Number 1, 2 and the operator
6. Press **A** to see the Equal
